DrawScope — Explore every draw. Understand every pattern.

1. Keep all files together in this extracted folder.
2. Run DrawScope.exe or launch-portable.bat.
3. No installation or administrator access is required.
4. DrawScope stores its controlled data in config, data, logs, cache, and runtime here.
5. Close DrawScope and delete this folder to remove the application.

The release includes an offline historical database for Powerball, Mega Millions,
Illinois Lotto, Lucky Day Lotto, Pick 3, and Pick 4. Open Draw explorer to filter it by
game, session, year, or number. Data quality lists the exact coverage and known gaps.

Saved annual archive pages can be imported from imports\lottery-net. Open Data updates
inside DrawScope for the exact allowed file names, year ranges, validation status, and
source-policy explanation. Lottery.net live extraction is disabled because its published
terms prohibit automated data mining and extraction.

Windows x64 and Microsoft Edge WebView2 are required. This portable package validates
the runtime but does not install WebView2 or another system component.

DrawScope is historical analysis software. It does not predict winning numbers.
Lottery drawings are designed to be random and independent. Every valid combination
has equal theoretical probability in a fair drawing. Illinois games are for adults 18+.
