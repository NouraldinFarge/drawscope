DrawScope — installed Windows distribution

DrawScope is installed for the current Windows user and does not require administrator
access. Launch it from the Start menu or run DrawScope.exe from the selected install
folder. Keep DrawScope.exe, drawscope-engine.exe, the data folder, and the other installed
resources together.

The installer includes an offline historical database for Powerball, Mega Millions,
Illinois Lotto, Lucky Day Lotto, Pick 3, and Pick 4. Open Draw explorer to filter it by
game, session, year, or number. Data quality lists exact coverage and known gaps.

Saved annual archive pages can be placed in imports\lottery-net and imported from Data
updates. Lottery.net live extraction is disabled because its published terms prohibit
automated data mining and extraction.

Windows x64 and Microsoft Edge WebView2 are required. If a suitable WebView2 runtime is
missing, the installer may use Microsoft's official bootstrapper and therefore requires
an internet connection for that prerequisite.

Use the DrawScope uninstall entry in Windows Settings or the Start menu to remove known
application files. Uninstalling does not silently delete the writable user database,
saved imports, or user configuration. Back up and remove those files separately only if
you explicitly intend to delete your research data.

DrawScope is historical analysis software. It does not predict winning numbers, improve
lottery odds, or provide betting advice. Every valid combination retains equal
theoretical probability in a fair independent drawing. Illinois games are for adults
18+.
