# Reproducible DrawScope examples

Examples are version-bound evidence artifacts, not promotional predictions. Each bundle
must identify the application, engine contract, methodology, archive hash, fixed request,
and exact reproduction procedure.

| Example | What it proves |
| --- | --- |
| [`powerball-retrospective-v0.6.5`](powerball-retrospective-v0.6.5/README.md) | A complete full-archive result produced through `DrawScope.exe` → `drawscope-engine.exe`, with confidence 5/100 under the 49/100 retrospective cap and a `do_not_use_to_choose_numbers` recommendation |

The public site is allowed to display analytical values only from a current verified
bundle. A future version bump therefore requires a newly generated example before the
site or release pipeline can pass.
